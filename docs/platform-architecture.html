          SPEC-DRIVEN ARCHITECTURE (SPECS 001–010)
          
Architectural Evolution & Feature Packages

          

            

              

                Spec 001 — Core Project Platform
                specs/001-project-platform
              

              
Establishes Traefik ingress, pure-stdlib Go Auth Gateway, Keycloak Google broker, PostgreSQL StatefulSet, Restricted PSS, and 1/n resource slicing.

            

            

              

                Spec 002 — Internal Cluster Vault (Zero-Plaintext)
                specs/002-internal-cluster-vault
              

              
Introduces self-hosted OpenBao 2.0.0, vault-db-proxy (PostgreSQL wire auth injector), and vault-registry-proxy (GHCR PAT injector) so pods hold zero secrets.

            

            

              

                Spec 003 — Minimal VM Bootstrap
                specs/003-minimal-vm-bootstrap
              

              
Ansible playbook (bootstrap/bootstrap.yml) validating host preflight, installing pinned K3s v1.35.9+k3s1, and verifying CoreDNS + reconciler readiness.

            

            

              

                Spec 004 — Flux GitOps Reconciliation & Admission
                specs/004-flux-gitops-reconciliation
              

              
Defines the Flux DAG, ValidatingAdmissionPolicy blocking manual kubectl edits, and R3 amendment allowing postBuild.substitute.AUTH_HOST on ingress only.

            

            

              

                Spec 005 — Post-Vault Automation
                specs/005-post-vault-automation
              

              
Automates Kubernetes SA auth binding (vault-configure-k8s-auth.sh), secret seeding, and initContainer memory secret hydration after OpenBao unseal.

            

            

              

                Spec 006 & 007 — Separate Project Auth & 3-Probe + CORS
                specs/006-separate-project-auth & 007-pn-readiness-restart
              

              
Decouples project doors (sign-in.yaml mode: none|shared), separates startupProbe / readinessProbe / livenessProbe, and mandates PUBLIC_APP_URL in ALLOWED_ORIGINS.

            

            

              

                Spec 008 — Platform-Owned TLS Termination
                specs/008-platform-tls-termination
              

              
Centralizes all cert-manager Certificates (auth-tls, pn-tls) in namespace platform behind Traefik TLSStore default; projects declare tls: {} with zero TLS secrets.

            

            

              

                Spec 009 — Host-Scoped Session Cookies & Direct Google Auth
                specs/009-host-scoped-shared-auth
              

              
Redirects /oauth/start straight to Google OAuth (kc_idp_hint=google) skipping intermediate Keycloak screens. First Google SSO creates the Keycloak user via google jit first broker login (AUTH-01).

            

            

              

                Spec 010 — Cilium + Hubble CNI & Visual Network Observability
                specs/010-cilium-hubble-observability
              

              
Replaces K3s Flannel with Git-vendored Cilium v1.20.3 + Hubble UI v0.13.6, tightens OpenBao egress via CiliumNetworkPolicy (toEntities: ["kube-apiserver"]), and adds scripts/open-hubble-ui.sh.
