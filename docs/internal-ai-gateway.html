Why You Never Need a Vault Root Token to Add the Gemini Key — or to Access OpenBao

Your cluster already has OpenBao auth/kubernetes enabled! That means Kubernetes pods (and your kubectl CLI) log into OpenBao automatically using Kubernetes ServiceAccount JWTs—zero Vault Root Token memorization required.

1. Why Separate :8080 & :8081?

pn-backend must reach :8080 for AI calls. If /admin/enable lived on 0.0.0.0:8080, a buggy or compromised pn-backend pod could call :8080/admin/enable?project=pn and turn its own Kill Switch back ON!

2. Why Loopback (127.0.0.1:8081)?

Inside the vault-ai-proxy container, lo (127.0.0.1) is a private internal wire that never leaves the pod. No other pod on the cluster network (eth0) can ever connect to 127.0.0.1:8081—only host kubelet via your kubectl tunnel can!

3. Direct In-Memory Table Access (<1µs)

Both Server #1 (dataMux :8080) and Server #2 (adminMux :8081) run inside the exact same Go process and share the same Go pointer (*AIProxy with sync.RWMutex). Flipping the switch on :8081 mutates the RAM struct directly in <1 microsecond!

Three-Probe Architecture (`startupProbe` + `readinessProbe` + `livenessProbe`) & Live Vulnerability Self-Test

Before Kubernetes ever marks vault-ai-proxy Ready or routes a single packet to it, startupProbe (GET :8080/startupz) executes a 5-Point Live Kill-Switch & Vulnerability Self-Audit in RAM using a synthetic __selftest__ slot:

STARTUP PROBE: 200 OK (5/5 CHECKS PASSED)
1. startupProbe GET :8080/startupz

Runs on boot before traffic is allowed. Executes the 5-Point Kill-Switch & Vulnerability Self-Drill below and loads persisted switch state from OpenBao. If ANY check fails, returns 500 and halts rollout!

2. readinessProbe GET :8080/readyz

Runs every 10s. Verifies 127.0.0.1:8081 loopback listener is still strictly local (IsLoopback()==true), startup self-test passed, and openbao:8200 is reachable. Fails ➔ Ready=False (no restart storm).

3. livenessProbe GET :8080/healthz

Runs every 15s. Process-local only (200 OK, zero external calls per CONTRACT_PROBES_READINESS.md). Restarts container only if the Go process itself deadlocks.
