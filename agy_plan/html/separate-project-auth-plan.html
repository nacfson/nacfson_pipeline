Separate project entry from sign-in

Branch 006-separate-project-auth · 2026-10-09 · Spec specs/006-separate-project-auth/spec.md

The visitor road into a project stays that project's door. Sign-in only answers who the user is, and only after the project asks. Project PN keeps its site on port 80 and its API on port 8080. The sign-in check comes off those routes. Constitution 2.0.0 is part of the same revision.
