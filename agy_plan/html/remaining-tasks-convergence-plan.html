3. Detailed Breakdown of Remaining Tasks

Phase 1 • Immediate Execution Active Blocker
Task 1: OpenBao Vault Initialization, Unseal, and Secret Seeding

OpenBao was successfully bootstrapped as a StatefulSet with persistent storage and TLS listeners, but per security architecture (Principle V), it starts in an uninitialized and sealed state.

  • Subtask 1.1: Run Operator Init: Execute bao operator init -key-shares=1 -key-threshold=1 against openbao-0 via scripts/vault-init.sh.
  • Subtask 1.2: Capture Root Token & Unseal Key: Securely persist the unseal key and root token in the operator's password store.
  • Subtask 1.3: Unseal Vault Engine: Feed the unseal key to openbao-0, transitioning HTTP readiness from 501/503 to 200 OK.
  • Subtask 1.4: Enable Secrets Engines & Apply Policies: Mount KV v2 at kv/, transit engine, audit file logger, and apply RBAC policies (deploy/platform/vault/policies/).
  • Subtask 1.5: Seed 11 Mandatory Platform Credentials: Run scripts/vault-seed-inventory.sh to generate and store credentials for Keycloak, Postgres, GHCR pull secrets, and Go Auth Gateway HMAC.
