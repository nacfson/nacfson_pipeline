2. Key Architectural Decisions & Clarifications

Area Decision Why It Matters
Phased Observability
(FR-003, FR-004, FR-005, FR-008)		 Deploy Cilium + Hubble Relay + Hubble UI alone in Phase 1 (0 Grafana/Prometheus/Loki pods, bounded ring buffer 4095); enable :9965/metrics (dns,drop,tcp,flow) and :4245 gRPC now. Provides immediate visual network topology and policy drop debugging with minimal RAM overhead while keeping Phase 2 Grafana attachment zero-touch.
GitOps + Bootstrap CNI
(FR-001, FR-002, FR-009)		 Single Git-owned manifest bundle (deploy/platform/cni/) applied during Ansible bootstrap (bootstrap/tasks/install.yml) and reconciled by FluxCD (cni layer). When K3s boots with --flannel-backend=none --disable-network-policy, applying deploy/platform/cni/ brings the node and CoreDNS to Ready while keeping 100% of CNI resources in Git and budgeted by platform-preflight.py.
OpenBao API Server Egress
(FR-006, SC-003)		 Replace ipBlock: 0.0.0.0/0 in deploy/platform/vault/network-policy.yaml with CiliumNetworkPolicy toEntities: ["kube-apiserver"] on TCP 443/6443. Under Cilium, ipBlock: 0.0.0.0/0 matches only reserved:world (external internet) and drops DNATted kube-apiserver traffic. toEntities: ["kube-apiserver"] fixes TokenReview and blocks external internet egress from OpenBao.
Private Tunnel & Automated Verification
(FR-010, FR-013, SC-005)		 Keep svc/hubble-ui as ClusterIP only and provide scripts/open-hubble-ui.sh (tunneling to http://127.0.0.1:12000 by default, and running all 5 FR-013 checks via --verify). Preserves the strict public-surface allowlist (Constitution Principle III) and gives a single command for both interactive browsing and automated verification.
