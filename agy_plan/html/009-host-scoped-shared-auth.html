Branch: 009-host-scoped-shared-auth Constitution v2.2.0: PASS Zero Cookies / 4-Layer BFF

Implementation Plan: Backend-First Headless Login Logic & Shared Project Authentication

Eliminates cross-subdomain cookie rejections (PLATFORM_SESSION) and missing or expired auth state errors by delegating the entire Login UI to the project Frontend, keeping all OAuth/Keycloak session tokens sealed inside the internal Gateway/Keycloak boundary, and routing all authentication via Frontend ➔ Project Backend ➔ Internal Gateway/Keycloak ➔ Project Backend ➔ Frontend.

2. Scope Breakdown

1. Stateless Encrypted PKCE & Direct Google Login

In gateway/internal/auth/, add AES-256-GCM encryption for StatePayload (carrying the PKCE code_verifier inside state with a 10-minute TTL, eliminating OIDC_AUTH_STATE cookie failures) and append kc_idp_hint=google on /oauth/start.

2. Vault-Sealed session_handle & Ticket Exchange

Replace cross-subdomain PLATFORM_SESSION cookies on /oauth/callback with a Vault-encrypted session_handle and a 60-second single-use handoff ticket redeemed by the Project Backend via POST /auth/exchange.

3. Canonical Issuer & Active Token Refresh

Fix HandleForwardAuth (/auth) to validate against CanonicalIssuer() and introspect/refresh actual OAuth tokens sealed inside session_handle instead of passing a session UUID to token introspection.

4. Shared Verification Package (gateway/pkg/projectauth)

Provide a reusable Go 1.22 stdlib-only package implementing /api/auth/login, /api/auth/callback, /api/auth/session, /api/auth/logout, and RequireAuth middleware.
